# Granola Clone: descargas

Instaladores para Windows (64 bits) de un proyecto personal de notas de reuniones con transcripción en vivo e IA, inspirado en Granola. No está afiliado a Granola.

**Descarga:** [última versión](../../releases/latest)

- `Granola.Clone-Setup-*.exe`: instalador (recomendado).
- `Granola.Clone-Portable-*.exe`: versión portátil, sin instalar.

No van firmados: Windows SmartScreen avisará la primera vez (*Más información → Ejecutar de todas formas*).

Para usarla necesitas tus propias claves en **Ajustes**: Deepgram (transcripción) y una clave de Anthropic o el CLI de Claude ya iniciado. Tus notas y claves se guardan solo en tu equipo.
